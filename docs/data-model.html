Every table from apps/api/db/schema.sql and migrations 002–022, with its columns and keys. PK = primary key, FK = foreign key, UK = unique; composite primary keys (join and approval-step tables) are noted in the column comments. The append-only ledgers are signatures, quiz_attempts, policy_approvals and audit_log (UPDATE/DELETE revoked at the database grant layer — ADR-109). Four database views derive effective membership and admin sets and are not shown as tables: platform_group_members, admin_users, group_effective_members, and effective_group_membership (the single source of truth for group reach — migration 018).
