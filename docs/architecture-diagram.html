Birgma Governance Portal — Solution Architecture

Rendered from architecture-diagram.mmd. To edit in Lucidchart: File → Import Diagram → Mermaid.


  

  

    Three containers behind Microsoft Entra ID. The browser authenticates against the SPA app
    registration and calls the API with a delegated token; nginx terminates TLS and proxies
    /api; the API validates every token, enforces role-based access, and is the only
    component that talks to PostgreSQL, Microsoft Graph and SharePoint. See
    ARCHITECTURE.md and ARCHITECTURE-DECISIONS.md for detail.
