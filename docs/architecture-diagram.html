Three containers behind Microsoft Entra ID. The browser authenticates against the SPA app registration and calls the API with a delegated token; nginx terminates TLS and proxies /api; the API validates every token, enforces role-based access, and is the only component that talks to PostgreSQL, Microsoft Graph and SharePoint. See ARCHITECTURE-AND-DECISIONS.md for detail. This is a container/service view — the datastore is one node; for the tables drawn as tables (columns + keys) see the entity-relationship diagram in data-model.mmd / data-model.html.
