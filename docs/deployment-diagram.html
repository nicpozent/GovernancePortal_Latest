Runtime topology of the Docker Compose stack (deploy/docker-compose.yml): the web container (nginx) is the only published edge — :443 TLS with a :80→443 redirect — and reverse-proxies /api to the api container on the internal Docker network. The db container publishes :5432 to 127.0.0.1 only (loopback), so PostgreSQL is not reachable from the VM network. State lives in the pgdata volume and the uploads/ backups/certs mounts. Identity and documents come from Microsoft Entra ID and Graph/SharePoint (external, enterprise-shared). The dashed block is the Azure-native target (ADR-117): Container Apps + managed PostgreSQL (PITR) + Blob + Key Vault + private endpoints — a lift-and-shift, not a rewrite.
